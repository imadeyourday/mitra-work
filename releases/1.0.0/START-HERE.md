# Mitra Work
## Version 1.0.0 · 24 November 2026

A portable operating reference for useful work, careful judgment and dependable continuation.

The package is ready to adopt as a fresh work-local starting point. It carries reusable procedures, examples and templates. It contains no prior personal conversations or project history. Approval to adopt this package is treated as established; continue to use the actual permissions and tools granted for each work task.

## Start with one file

1. Create or open your private work Project in your employer's Claude Enterprise account.
2. Put PROJECT-INSTRUCTIONS.txt into the Project instructions field.
3. Add GREENFIELD-REFERENCE.md to the Project's knowledge.
4. Start a conversation with the text in FIRST-SESSION.txt.

This provides the complete reference without requiring a personal repository connection. Keep work records in the employer's approved systems. Use the memory settings available in the employer account; for Project-specific memory, turn Use account memory off where that control is available. Do not claim a memory setting was changed without observing it.

## Add the focused Skills

If native Skills are available in the employer account, add the four files from skill-zips through Customize → Skills → + → Create skill → Upload a skill:

- mitra-continue-execute-1.0.0.zip
- mitra-research-judge-1.0.0.zip
- mitra-review-improve-1.0.0.zip
- mitra-organize-handoff-1.0.0.zip

These are separate upload files. The outer Mitra Work distribution ZIP is a delivery kit, not a single Skill upload.

Skills require the host's code-execution capability, although these four Skills contain only text. They use the same procedures as the combined reference. Do not create a second policy stack: keep the Project instructions as the stable entry and use the appropriate Skill or reference section for the task.

Skills can apply across the work account. None should carry personal context, credentials or project-specific private state.

## The working boundary

The imported methods are a fixed baseline. Work conversations, sources, artifacts, outcomes, memory and learned adaptations remain in employer-controlled systems. There is no personal callback, feedback submission, updater, credential, repository link or inference endpoint in this package.

A later generic release arrives as another deliberate import. It does not collect workplace results. Local adaptations remain separate and take their authority from the actual work context.

## First useful outcome

Choose one current work objective. Recover its applicable instructions and existing records, complete the smallest useful authorized step, inspect the result, and preserve an exact next action. Use the fictional exercises to check source judgment, scoped correction and continuation.

This release is a procedure and reference package. A supported save operation is required for persistent records; the package itself does not create a background worker, scheduler or storage service. Check whether a result was actually saved and whether a receiving conversation actually recovered it.
